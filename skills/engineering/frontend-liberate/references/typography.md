# Typography

Saans is Liberate's primary typeface. Its clear, contemporary character gives the brand a confident and consistent expression across headlines, supporting copy, and body text.

| Weight | Use |
| --- | --- |
| Semibold | Hero headlines and the brand's most important messages. It brings confidence, boldness, and stability to prominent moments. |
| Medium | Supporting copy and intermediate levels of hierarchy. |
| Regular | Body text. |

When Saans is unavailable, use Arial as the primary fallback. Arial is a free, widely accessible alternative that preserves the brand's clean, contemporary character.

In a Tailwind CSS project, set the target project's sans font token to `"Saans", Arial, sans-serif` when Saans is available, or `Arial, sans-serif` otherwise. Use weights 600 for Semibold, 500 for Medium, and 400 for Regular. This font choice replaces the generic sans stack shown in the color reference.
